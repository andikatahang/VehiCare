## Phase Goal

**As a** vehicle owner, **I want to** add, view, edit, and delete my vehicles (with an optional photo) on both Android and iOS, **so that** I have a trusted offline record of every vehicle I own.

> Roadmap fidelity note: the ROADMAP `**Goal:**` line for Phase 1 is outcome-form, not user-story form. The story above is the MVP-mode rendering of it. Run `/gsd-mvp-phase 1` if the ROADMAP line should itself be rewritten into story form.

<objective>
Replace the name-only form from plan 01-04 with the real single-screen Add/Edit form: name, make, model, year (digits-only), license plate, and a Car · Motorcycle · Truck type picker, with only the name required, inline validation, and an honest Saving/Save-failed contract.

Purpose: this is the VEH-01 capability (a user can add a vehicle with the full field set) and the VEH-03 capability (a user can edit any of those fields). It is also the plan that makes the form genuinely reusable for Edit, so the Detail screen in plan 01-09 only has to navigate here — no second form is ever authored (D-08). The photo block is deliberately absent: plan 01-08 appends it as the last element of this same form, which is why the field order (C-1) puts the heaviest interaction last.

Output: one form that adds a vehicle with every field and edits an existing one in place, with validation the user can see and a save path that never silently loses input.
</objective>

    val make: String = "",
    val model: String = "",

enum class VehicleFormError { NAME_REQUIRED }    // maps to Res.string.error_name_required in the screen

object VehicleFormValidation {

    fun errorFor(values: VehicleFormValues): VehicleFormError?   // currently only NAME_REQUIRED
    fun sanitizeYear(raw: String): String                        // keep digits, take the first 4
    fun toVehicle(id: Long, values: VehicleFormValues): Vehicle  // blank optionals → null, type preserved, photoPath preserved
}

    data object Loading : VehicleEditUiState
    data class Ready(
        val values: VehicleFormValues,
