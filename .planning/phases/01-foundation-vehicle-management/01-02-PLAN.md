## Phase Goal

**As a** vehicle owner, **I want to** add, view, edit, and delete my vehicles (with an optional photo) on both Android and iOS, **so that** I have a trusted offline record of every vehicle I own.

<objective>
Make the shared UI layer real and prove it renders identically on both platforms: author the centralized string set, the three vehicle-type vector drawables, the theme tokens, and the two platform hosts around a single shared `App()` composable.

Purpose: D-17 forbids platform-specific UI duplication, so this plan establishes the one-and-only rendering path (Android `MainActivity` and iOS `ComposeUIViewController` both call the same `commonMain` composable) before any feature screen exists. Getting the neutral ink-on-white theme and the centralized string mechanism in place now means no later plan invents a color or hardcodes a label — both are the most common ways this contract erodes.

Output: The app launches on both platforms showing themed Compose UI driven entirely by shared code, with all user-facing copy read from Compose Resources.
</objective>
